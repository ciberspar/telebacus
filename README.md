# 📡 telebacus

**telebacus** es una plataforma web minimalista y moderna de streaming de televisión en vivo, diseñada para ofrecer acceso rápido a canales públicos y transmisiones globales en alta definición directamente desde el navegador, con compatibilidad total tanto para computadoras como para dispositivos móviles.

---

## ✨ Características Principales

* **Interfaz Cyber/Dark Minimalista:** Diseño limpio, optimizado para una navegación fluida tipo "zapping" sin distracciones.
* **Reproducción HLS Nativa:** Soporte integrado para reproducción fluida de streams `.m3u8` y compatibilidad optimizada para navegadores móviles (como Safari en iOS).
* **Filtros en Tiempo Real:** Buscador instantáneo por nombre y selector desplegable de países para encontrar contenidos al instante.
* **Multiplataforma:** Diseñado con un layout adaptable (*Responsive Design*) que se ajusta perfectamente a pantallas de celulares, tablets y escritorios.
* **Despliegue Instantáneo:** Estructurado en un único archivo web (`index.html`), ideal para alojarse sin complicaciones en **GitHub Pages**.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Estructura moderna y diseño visual con efectos de transparencia (`backdrop-filter`) y paleta de colores oscura.
* **JavaScript (ES6+):** Lógica de control de estado, manipulación del DOM y gestión de eventos asíncronos.
* **HLS.js:** Librería ligera para el soporte y decodificación de transmisiones de video en streaming.

---

## 🚀 Cómo usarlo localmente o desplegarlo

1. Cloná o descargá este repositorio.
2. Asegurate de tener el archivo principal renombrado como `index.html`.
3. Para probarlo en tu computadora, podés abrir el archivo directamente en tu navegador o usar una extensión de servidor local (como *Live Server* en VS Code).
4. Para subirlo a la web de forma gratuita, subí el archivo a tu repositorio de GitHub y activá **GitHub Pages** desde la sección de configuración (*Settings > Pages*).
